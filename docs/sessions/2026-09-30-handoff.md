## Open problem: coastal "boxes"
WorldCover labels near-shore sea as class 8 (water). The old builder turned it into ocean only where HYCOM (~9 km) said sea, which left
rectangular "water" boxes along **every coast in the world** at levels 5–8. Commit `0e398d2` fixes the builder (Copernicus GLO-30 `WBM`:
1 = ocean, 2 = lake, 3 = river), so new tiles are right. Verified: rebuilt Alibag tile 11/2876/811 is 64,821 ocean px, 120 water.

**Don't rebuild the world to fix it** (owner decision: re-pulling everything from Earth Engine is wasteful; worldwide rebuild run
36755105583 was cancelled). Instead:
1. Build a small **coast mask product** once from the same Copernicus WBM band (sea vs land/lake/river), at the level-8 grid and finer where
   needed, with a manifest. It's our own L2 product; no OSM needed.
2. **Patch the existing tiles locally:** in each tile's class channel (R byte), set 8 → 0 where the coast mask says sea. Touch only coastal
   tiles; leave tree/hillshade/NDVI/true colour alone. Write files in place (never rename folders under `web/public` while Vite runs).
3. Test on Alibag and on an inland lake (Chilika) and the Rann of Kutch; lakes and rivers must stay water. Then run on all levels 5–8.
